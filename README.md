# Roam Fund — Vietnam

A focused savings dashboard for a seven-day Vietnam trip from India. The target is ₹1,55,000 per person, based on upper-comfort 2026 estimates for flights, a six-night stay, sightseeing, food, local travel, visa costs and a price buffer.

Open `index.html` directly, or serve the directory with any static web server.

Savings entries, traveller count and the target month are stored locally in the browser.

## Deploy with GitHub Pages

This repository is ready to publish as a static GitHub Pages site from the repository root.

1. Push the `main` branch to GitHub:

   ```bash
   git push -u origin main
   ```

2. Open the repository on GitHub and go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then click **Save**.
5. Wait for the Pages deployment to finish. The site will be available at:

   `https://rutvi18.github.io/trip-budget/`

Future pushes to `main` will automatically republish the site.
