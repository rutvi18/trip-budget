# Roam Fund — Vietnam

A focused savings dashboard for a seven-day Vietnam trip from India. The initial target is ₹1,50,000 per person, based on upper-comfort 2026 estimates for flights, a six-night stay, sightseeing, food, local travel and a price buffer.

Open `index.html` directly, or serve the directory with any static web server.

Savings entries, traveller count and the target month are stored locally in the browser.
